# Canvas → Things Mail Bridge (Work in Progress)

This repository will host an automation utility that watches Canvas LMS for new assignments and emails them into Things 3 via Mail to Things. The project is currently in planning and scaffolding stages.

## Current Status
- Repository structure initialized (src, config, data, docs, tests, GitHub Actions workflow skeleton).
- Requirement specification lives in `opencode.txt`.
- Implementation will proceed in clearly defined steps (collector, notifier, CLI, workflow, documentation).

Stay tuned for detailed setup instructions once the core functionality is in place.
